# Proyecto-asir
Documentacion del proyecto de PIMA (1º Asir)
 Descripción de la empresa
Pequeña empresa que trabaja con varios ordenadores y una impresora compartida. Actualmente no tiene una organización informática clara, lo que le causa problemas en el día a día.

 Problemas informáticos detectados
1. La impresora solo funciona desde uno de los ordenadores.
2. Los documentos importantes están guardados en un único equipo.
3. Si se avería ese ordenador, podrían perder información.

 Para qué sirve este repositorio
Este repositorio sirve para documentar el proyecto: describir la empresa, recoger los problemas informáticos encontrados y guardar las soluciones propuestas (por ejemplo, compartir la impresora en red y crear copias de seguridad de los documentos).
